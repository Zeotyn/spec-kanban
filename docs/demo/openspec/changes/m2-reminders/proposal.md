## Why

Todos with a due date pass by unnoticed; users want a nudge before something is due.

## What Changes

- Optional reminder time on every todo
- Local notification at the reminder time, with "Done" and "Snooze 1 h" actions

## Capabilities

### New Capabilities
- `reminders`: notify the user about a todo at a chosen time

## Impact

- Notification permission prompt on first use
