## Why

The app is bright white at night, and the most requested feature in the feedback
form is a dark theme.

## What Changes

- Add a dark theme next to the current light one
- Follow the system setting by default, with a manual override in Settings
- Move all colours into theme tokens

## Capabilities

### New Capabilities
- `theming`: light and dark themes, chosen by system setting or by the user

## Impact

- Every screen's stylesheet; screenshots in the store listing
