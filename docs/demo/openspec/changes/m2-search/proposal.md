## Why

With a few hundred notes, scrolling is no longer a way to find anything. Users ask
for a search box more than for any other feature.

## What Changes

- A search box above the note list that filters as you type
- Matches in title and body, ignoring case and accents
- Highlight the matched words in the results
- `/` focuses the search box from anywhere

## Capabilities

### New Capabilities
- `search`: full-text search over a user's notes and todos

## Impact

- New full-text index in the local database
- Note list component gains a filtered mode
